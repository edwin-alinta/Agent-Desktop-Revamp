  • Page 1 · Verification — verticalStackContainers of input+button. On page load: Set Variable writes {{scripter.callANI}} into phone. Set Variable also loads IVR context vars from flow (blank when IVR did not validate). Verify button invokes CORE.searchCustomerByIdentityCheck; a Decision + Change Page → Servicing fires on success. On failure, {{attempts}} is incremented; Decision fires Change Page → Unable to Verify when {{attempts}} ≥ 3.
  • Page 2 · Servicing — verified strip uses interpolated text nodes. Perform Screen Pop action runs on page-load (native, already enabled on live script). Servicing buttons (Initiate Payment / DDR / Add Customer Details) are the existing components. In restricted mode a script-variable {{restricted}} disables Payment + DDR (native disabled = variable binding).
  • Page 3 · Unable to Verify — four buttons in a stack: SMS (future Data Action), Transfer (existing Genesys transfer control), Continue-restricted (sets {{restricted}}=true and Change Page → Servicing), End (interaction disconnect action with wrap code).
  • MTWC panel = existing webPage component — unchanged.
